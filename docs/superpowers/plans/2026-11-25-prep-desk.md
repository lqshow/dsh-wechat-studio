# 「备稿」模块（纸条 × 选题袋）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the pre-drafting `备稿` workspace (`纸条 × 选题袋/商单袋`) across storage, Host HTTP API, CLI, and React UI, linked cleanly to `稿面`, `排期`, and zero-cost `发布防踩坑体检`.

**Architecture:** `prep.json` lives in a dedicated `JsonStore` alongside `prep-assets/` under `Store.root` (`~/.dsh/wechat-studio/`), keeping `articles/` untouched for legacy drafts. Cross-store promotion uses an idempotent 4-step protocol (`pendingPromotion` → `store.update` → `prepStore.update` → async pipeline) with startup/read reconciliation instead of nested locks; promoted bags forbid hard delete so articles never regress to stale snapshots.

**Tech Stack:** Node.js 20+ (ES Modules, zero new runtime deps, `node:test`), React 18 + esbuild (`npm run build`), existing `JsonStore` / `Store` / `Pipeline` / `runPreflight` / `wechat-studio` CLI.

**Spec:** [docs/superpowers/specs/2026-11-25-prep-desk-design.md](../specs/2026-11-25-prep-desk-design.md)

## Global Constraints

- Zero new runtime dependencies; `npm run build`, `npm test`, and `npm run check:package` must pass.
- Backward-compatible storage: `prep.json` + `prep-assets/` isolated from existing `index.json` / `articles/<id>/`.
- Offline-first: every feature except the 3 explicit AI triggers (`extract-brief`, `cluster-notes`, `mode: 'ai'` draft) works with zero model and zero Cloudinary config.
- Capacity & length caps enforced server-side: max `200` bags total, `2000` notes total, `200` notes per bag; title `120` chars, note text `4000` chars, partner `60` chars, sellingPoints `500` chars, `mustInclude`/`taboo` max `20` items × `120` chars each, `rawText` `20000` chars, image `10 MB`.
- Visual shell tokens inherit DSH theme vars (`client/styles.css`) for full light/dark support; editorial typography (`Songti SC` serif, terracotta `#a84b2c` / `#e38562`, warm linen/charcoal sponsored cards).

## Review Focus

1. **Fake-extension or oversized image upload** (e.g., SVG/HTML disguised as `.png`, or >10 MB) → rejected with `400`, zero files written to `prep-assets/`. *(Pinned in Tasks 1 & 5)*
2. **Crash mid-promotion or retried `POST prep/bags/promote` with same `operationId`** → returns the same `articleId`, never creates duplicate articles, and `reconcilePrep` finishes binding before `pipeline.draft` runs. *(Pinned in Task 2)*
3. **Code-fence / image-URL false positives in sponsored preflight** → required keyword inside a fenced code block still warns missing; taboo word inside an image URL does not trigger; required promo URL inside `[link](https://...)` matches via `extractLinks()`. *(Pinned in Task 3)*
4. **Deleting a note whose local image is still referenced by an offline-imported article** → note record deletes, but `prep-assets/<assetId>.<ext>` remains on disk while referenced by any article block. *(Pinned in Tasks 1 & 5)*
5. **Confirming a stale AI cluster after a note was moved or deleted** → `prep/notes/batch` re-checks `bagId === null` on write, moves only still-free notes without stealing from other bags, and reports skipped count. *(Pinned in Tasks 4 & 5)*
